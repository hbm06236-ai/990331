# 식품 품질관리 포트폴리오 홈페이지 초안

## 파일 구성
- `index.html` : 전체 페이지 구조
- `styles.css` : 반응형 스타일
- `app.js` : 모바일 메뉴, 필터, 모달 기능

## 실행 방법
세 파일을 같은 폴더에 둔 뒤 `index.html`을 브라우저에서 열면 바로 실행됩니다.

## 수정이 필요한 항목
1. 연락처/이메일
2. 프로필 이미지
3. 실제 이력서 PDF 경로
4. 식품공전·식품위생법 콘텐츠
5. 포트폴리오 결과물 이미지/PDF

## 반응형 기준
- Desktop: 981px 이상
- Tablet: 681px ~ 980px
- Mobile: 680px 이하
